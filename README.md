### About me

I'm Vince, a software developer interested in the intersection of **computer vision, autonomous systems, and software engineering**.

I enjoy building end-to-end projects—from simulation and perception pipelines to real-time interfaces and interactive data visualizations. I care about **clear architecture, reproducible experiments, and software that behaves predictably when things go wrong**.

**Cooperative perception & risk-aware braking**
